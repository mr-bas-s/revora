# Revora EV Engine

A static, backend-free EV sound experience designed for the Tesla in-car browser.

Revora EV Engine turns live GPS speed into realtime synthesized engine sound with a virtual six-speed automatic gearbox. The dashboard includes eight original sound profiles, tap/hold REV, a manual speed test, animated performance gauges, shift lights, live telemetry, master volume, a 120 Hz bass shelf and adjustable drivetrain tuning.

Location readings stay in the browser and are never transmitted or stored. GPS data should only be observed while safely parked or by a passenger.
