# Revora EV Engine

A static, backend-free EV sound experience designed for the Tesla in-car browser.

Revora EV Engine turns live GPS speed into a realtime synthesized American V8 sound with a virtual six-speed automatic gearbox. Its dashboard shows GPS speed, virtual RPM, gear, position, update frequency and browser/API compatibility.

Location readings stay in the browser and are never transmitted or stored. GPS data should only be observed while safely parked or by a passenger.
